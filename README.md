🧠 Customer Segmentation using Machine Learning

🚀 Customer Segmentation App helps businesses understand their customers by grouping them into meaningful clusters using unsupervised learning techniques like KMeans and DBSCAN.

This project includes data preprocessing, model training, dimensionality reduction, and an interactive Streamlit web app for real-time predictions.



📊 Project Overview

Customer segmentation is a crucial marketing strategy that divides customers into groups based on shared characteristics like spending behavior, demographics, and preferences.
This project uses clustering algorithms to identify unique customer groups and visualize patterns in customer data.
